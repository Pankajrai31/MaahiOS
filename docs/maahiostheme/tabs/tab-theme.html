Typography

MaahiOS uses two font stacks: a proportional UI font and a monospaced font for data/code.

VariableValueUsage
--os-font"Segoe UI", Tahoma, Geneva, Verdana, sans-serifAll UI text: labels, buttons, menus, titles
--os-font-mono"Cascadia Mono", "Consolas", monospacePIDs, addresses, code, terminal, file sizes

Type Scale

16px bold — Window titlebar text
14px semibold — Section headers
12px regular — Standard body text (default)
11px — Menu items, table cells, sidebar items, toolbar labels
10px — Status bars, info bars, small labels, legends
9px — Badge text, graph labels, secondary hints
11px mono — PID, addresses, file paths, code

Design Principles for AI Agents

When generating MaahiOS UI code, follow these rules:

#PrincipleDetails
1Use CSS variablesNever hardcode colours. Always use var(--os-*) tokens.
23D beveled bordersRaised elements: border-color: var(--bevel-light) var(--bevel-dark) var(--bevel-dark) var(--bevel-light). Sunken: reverse order.
3Chrome surfacesWindow frames, toolbars, menubars all use var(--os-chrome) as background.
4Gradient titlebarsActive: linear-gradient(to right, var(--titlebar-start), var(--titlebar-end)). Inactive: use inactive vars.
5SVG icons at consistent sizes32px for full, 16px for toolbar/titlebar, 10px for window buttons. All from icons/icon-*.svg.
6Small font sizes11px default for data-dense UI. 10px for status bars. 9px for badges/labels.
7Selection = accent colourSelected rows, active sidebar items, focused tabs all use var(--os-accent) background with white text.
8Status badgesUse .os-badge variants: .os-badge-teal (healthy/running), .os-badge-warning (warning), .os-badge-danger (error), .os-badge-default (idle).
9Window structure orderTitlebar → Menubar → Toolbar → Address bar (optional) → Body → Status bar. Always.
10Accessibility of textPrimary text #1A1A2E on white/chrome surfaces. White text on accent/gradient/dark backgrounds.
